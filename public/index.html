        About this app

        This is a small Todo List application built with plain PHP and MySQL — no framework, no build step.

        • Backend: PHP 8, PDO, prepared statements
        • Database: MySQL, configured via a .env file
        • Frontend: Vanilla HTML/CSS/JS, hash-based routing across 5 screens
        • API: REST endpoints under /api/todos (GET, POST, PUT, PATCH, DELETE)

        Screens

        1. Dashboard — live counts and recent activity
        2. All Todos — full list with add form and filters
        3. Add Todo — dedicated create form
        4. Completed — filtered view of finished todos
        5. About — this static reference page

        Version 1.0.0 — this page's content is static and does not query the database.
